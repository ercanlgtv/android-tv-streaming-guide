# Hidden Gems — Lesser-Known Quality Projects

| #   | App                     | GitHub                                                                    | Stars | Why It Deserves Attention                                                                                                                                                                                        |
| --- | ----------------------- | ------------------------------------------------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Nexio**               | [johnneerdael/nexio](https://github.com/johnneerdael/nexio)               | 19★   | Full Stremio addon compatibility + companion web portal for setup + debrid-aware playback + 49 releases in 3 months. Cross-device sync via web. Most actively developed low-star find.                           |
| 2   | **OwnTV**               | [ahXN00/OwnTV](https://github.com/ahXN00/OwnTV)                           | 225★  | Dual-engine IPTV: libmpv for movies/series (better codec support), ExoPlayer for instant live TV. 17 releases in one month. Beautiful modern Android TV UI. Explosive growth.                                    |
| 3   | **Flixorent**           | [Hashaleen420/Flixorent](https://github.com/Hashaleen420/Flixorent)       | 90★   | Zero-config debrid streaming — built-in Torrentio integration, no addons to install. Supports Real-Debrid, AllDebrid, Premiumize, TorBox. Chromecast. Auto-ranks 4K→1080p→720p by seeds.                         |
| 4   | **Hikari**              | [Hflott/hikari_app](https://github.com/Hflott/hikari_app)                 | 2★    | Only 2 stars but architecture is genuinely excellent. Custom HAP addon protocol for torrent sources, AniList sync, intelligent torrent ranking, batch series support. Premium UI for Android TV.                 |
| 5   | **NyanTV**              | [NyanTV/NyanTV](https://github.com/NyanTV/NyanTV)                         | 64★   | The only purpose-built tracking app for Android TV. Combines anime tracking (AniList, MAL) with western content (Simkl). Beautiful Compose UI. Fork of AnymeX.                                                   |
| 6   | **Strix**               | [isnow-git/strix](https://github.com/isnow-git/strix)                     | 0★    | Best code quality of any project found. Purpose-built for low-RAM budget Android TV sets. Jetpack Compose for TV, D-pad-first. Apache 2.0. Exceptionally well-engineered.                                        |
| 7   | **JellyPlay**           | [raulshma/jellyplay](https://github.com/raulshma/jellyplay)               | New   | Most feature-rich Jellyfin Android client. Triple engine (ExoPlayer, libmpv, LibVLC). SyncPlay watch parties, Jellyseerr/Overseerr integration, offline downloads, IPTV, admin dashboard. Rare SyncPlay support. |
| 8   | **LitPlayer**           | [daluobo/LitPlayer-release](https://github.com/daluobo/LitPlayer-release) | 176★  | Supports every network protocol: SMB, WebDAV, FTP, Jellyfin, UPnP. Material 3 design. Separate TV build. Lite variant for old devices.                                                                           |
| 9   | **Cineflux**            | [sauravchandra/cineflux](https://github.com/sauravchandra/cineflux)       | New   | Native libtorrent4j engine on Android TV. Letterboxd curated categories (65+ genres). Transmission integration. Auto subtitles via SubDL. MIT license.                                                           |
| 10  | **ThystTV**             | [tzii/ThystTV](https://github.com/tzii/ThystTV)                           | 24★   | AGPL-3.0 fork of Xtra Twitch client with significant polish. Floating chat overlay, local watch-history insights, large-screen optimized.                                                                        |
| 11  | **Aperture**            | [XDanfr/Aperture](https://github.com/XDanfr/Aperture)                     | 8★    | Brand new Material 3 media player for Android TV. Jetpack Compose for TV, Media3/ExoPlayer. Clean, minimal, beautiful. Has Discord community.                                                                    |
| 12  | **Lumera**              | [LumeraD3v/Lumera](https://github.com/LumeraD3v/Lumera)                   | 201★  | Full Stremio addon support. Stremio account import. Unique features: IntroDb skip intro/outro, adaptive HLS/DASH, source switching mid-playback. Lighter alternative to Nuvio.                                   |
| 13  | **Debrify**             | [varunsalian/debrify](https://github.com/varunsalian/debrify)             | 312★  | Rare combination: debrid manager + Stremio addon support + built-in libmpv player. Cross-platform (Android/iOS/Windows/Mac/Linux). Download queue with resume.                                                   |
| 14  | **Sozo (Soplay)**       | [professorDeveloper/sozo](https://github.com/professorDeveloper/sozo)     | 27★   | The only non-fork app that can natively load CloudStream `.cs3` plugins via DexClassLoader. ~70/73 plugins work. Flutter cross-platform.                                                                         |
| 15  | **Laposa Media Player** | [laposa/media-player](https://github.com/laposa/media-player)             | 3★    | Ultra-minimalist media player. Only 30MB, no cache growth. Supports NFS+SMB+SFTP. MIT license. Perfect for low-storage TVs.                                                                                      |
